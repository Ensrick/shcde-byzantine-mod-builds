# Credits

Byzantine units for Stronghold Crusader: Definitive Edition, dev build v0.1.0-dev.1. Mod by
Ensrick.

## 3D sources

The unit sprites in this build are our own renders. These free packs by Quaternius
(https://quaternius.com) went into them. Each is released under CC0 1.0 Universal, a public domain
dedication (https://creativecommons.org/publicdomain/zero/1.0/), so credit is not required; it is
given here with thanks. This download contains only rendered sprites, no model files.

| Pack | Creator | Licence | Used for |
|---|---|---|---|
| [Universal Animation Library](https://quaternius.com/packs/universalanimationlibrary.html) | Quaternius | CC0 1.0 | Animations |
| [Universal Animation Library 2](https://quaternius.com/packs/universalanimationlibrary2.html) | Quaternius | CC0 1.0 | Animations |
| [Ultimate Animated Animal Pack](https://quaternius.com/packs/ultimateanimatedanimals.html) | Quaternius | CC0 1.0 | The horse of the Cataphract and the Border Rider, and its animations |
| [Modular Character Outfits - Fantasy](https://quaternius.com/packs/modularcharacteroutfitsfantasy.html) | Quaternius | CC0 1.0 | The base character's body and clothing |
| [Universal Base Characters](https://quaternius.com/packs/universalbasecharacters.html) | Quaternius | CC0 1.0 | The base character's head and eyes |

The armour, weapons, shields, the icon and the horse gear were made for this mod.
